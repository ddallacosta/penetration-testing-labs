# Phishing Simulation Lab

## Obiettivo

Comprendere il funzionamento di una campagna di phishing attraverso una simulazione svolta in un ambiente controllato a scopo formativo.

## Ambiente e strumenti

- Kali Linux
- Social-Engineer Toolkit (SET)
- GoPhish
- Ambiente di laboratorio controllato

## Attività svolte

- Utilizzo di SET Toolkit per la simulazione di una pagina web
- Configurazione di un ambiente di test per una simulazione di phishing
- Utilizzo introduttivo di GoPhish per la gestione di una campagna simulata
- Osservazione del funzionamento e delle diverse fasi di una campagna di phishing
- Analisi degli elementi che possono rendere un messaggio o una pagina sospetti

## Risultato

Il laboratorio mi ha permesso di comprendere in modo pratico alcune delle tecniche utilizzate nelle campagne di phishing e l'importanza del loro riconoscimento dal punto di vista della sicurezza.

> Tutte le attività sono state svolte esclusivamente in ambiente controllato e a scopo formativo. Non sono stati utilizzati account, credenziali o destinatari reali.
